# Проверка сборки

Проверено локально:

- Синтаксис обоих shell-скриптов и JavaScript страницы LuCI.
- Синтаксис JSON меню и правил доступа.
- Исполнение обработчика с изолированными путями и имитацией команд OpenWrt: успешный импорт, включение автообновления, резервная копия, отсутствие секрета в выводе.
- Отказ декодера, неожиданный протокол адреса и многострочный результат не меняют конфигурацию; блокировка снимается.
- Ошибка применения службой возвращает отдельный код и сообщает о уже записанной конфигурации.

Не проверено: реальный LuCI/rpcd, запись через настоящий UCI, перезагрузка procd, фактическое обновление серверов и конкретная crypt5-ссылка пользователя. Имитационные проверки не доказывают работу этих частей на устройстве. Следующий необходимый этап — установка и проверка на совместимом роутере.
